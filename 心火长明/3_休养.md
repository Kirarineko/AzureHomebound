# 休养

回家后的第一个晚上，浅紫睡得很沉。

醒来的时候，阳光已经透过窗帘的缝隙洒进房间，在地板上画出一道金色的线。她试着动了动身体，右腿还有些酸软，但已经不疼了。

"浅紫，吃饭了！"母亲的声音从客厅传来。

浅紫掀开被子，脚踩在地板上，感觉踏实了不少。她推开房门，餐桌上已经摆好了早餐，只是寻常的小米粥、煎蛋、还有一碟酱菜。

"慢点吃，别烫着。"母亲坐在对面，看着她。

浅紫端起碗，小口小口地喝着粥。狐耳微微转动，捕捉着厨房里父亲洗碗的水声。

蓬松的尾巴从椅子边缘垂下来，尾尖随着她吞咽的动作轻轻晃动。

"今天别出门了，在家好好休息。"母亲说。

"嗯。"

吃完早餐，浅紫回到房间，躺在床上看着天花板。白色的天花板上有一道细小的裂纹，从角落一直延伸到吊灯旁边。

她闭上眼睛，脑子里浮现出茉璃的脸。

粉红色的瞳孔，黑色的猫耳，还有那条总是轻轻摆动的尾巴。

"茉璃……"她小声念了一遍这个名字。

尾巴从被子里探出来，在床单上扫了扫，又缩了回去。

接下来的几天，浅紫过得很规律。

每天早上被母亲叫起来吃饭，然后回房间躺着。中午母亲会变着花样做菜，红烧排骨、清蒸鲈鱼、番茄炒蛋，每一道都是她喜欢吃的。父亲则默默把她的装备洗干净，晾在阳台上，等干了又收进柜子里。

拥有了知觉的狐狸耳朵和尾巴带来了一些小麻烦。

第一天晚上，浅紫习惯性地侧睡，结果压到了左边的狐耳。一阵钝痛从耳朵根部传来，她"嘶"了一声，立刻翻身起来。狐耳的毛被压得乱七八糟，她用手捋了半天才恢复原状。

尾巴也是个问题。睡觉的时候不知道该放哪里，压着会麻，不压又硌得慌。最后她学着把尾巴卷在身侧，像猫一样蜷缩着睡。

或者当抱枕抱着睡

这两个器官早在半年前她就已经成功给自己加上了，未正式跨越就已经成功改变自己的身体，这样的天赋自然引来了周围许多人的羡慕。

只是...这还是第一次这么真实的感觉到它们。

洗澡也变得麻烦了。耳朵的毛沾水之后会变得沉甸甸的，贴在头皮上，要吹很久才能干。狐尾更麻烦，毛又厚又长，吸饱水后沉得像条围巾。

这几天的浅紫由父母照料一部分起居，母亲拿着吹风机，一边吹一边叹气。

"这俩东西，比头发还难伺候。"

"对不起……"

"道什么歉。"母亲的手指在狐耳根部轻轻挠了挠，"就是有点不习惯。"

休养到第三天，浅紫开始注意到身体的异常。

那天下午，她躺在床上，突然听到楼下传来一阵说话声。

"……今天的水果涨价了……"

"……是啊，西瓜都两块钱一斤了……"

"……正常啦，这个季节，都是大鹏的瓜……"

声音很清晰，像是就在耳边。浅紫愣了一下，坐起来，侧耳倾听。她的房间在五楼，楼下是小区的花园，平时根本听不到那么远的声音。

她走到窗边，往下看。两个保洁阿姨正站在花坛旁边聊天，距离她至少有二十米。

狐耳微微转动，像两根天线一样调整着方向。

浅紫发现，她甚至能听到更远处的声音——小区门口的门禁"滴滴"声、马路上汽车驶过的轮胎摩擦声、还有不知谁家传来的电视声。

"这也太灵敏了……"她小声说。

太多的声音让她有点不适应

到了第四天，另一种变化出现了。

浅紫坐在床上，闭上眼睛，试着感受自己体内的魔力。以前，她只能在特别关注时模糊地感觉到有能量的存在，像是血管里流淌的血液。

但现在不一样了。

她能微微感觉到体内汇聚的魔力，身体各处都有聚集。

浅紫睁开眼睛，有些惊讶。

她试着调动魔力，让它集中在右手掌心。微弱的光芒在掌心凝聚，比以前要快，也稳定一些。

"这就是……茉璃治疗的影响？"

母亲拉着她去做了一次体检。

抽血、量血压、测视力、拍片子……所有指标都正常，医生很惊讶：“这么重的伤居然几天就恢复成这样了，医学奇迹啊”。

浅紫叹了口气。

这种变化不在医学能解释的范畴内。

休养到第五天，浅紫终于忍不住了。

她拿起手机，打开通讯录，找到"茉璃"这个名字。

手指悬在屏幕上，打了几个字，又删掉。

"茉璃，你好……"太正式了，删掉。

"茉璃，我是浅紫……"太傻了，删掉。

"茉璃，我想你了……"更傻了，删掉。

浅紫把手机扔到一边，把脸埋进枕头里。狐耳在枕头上压得扁扁的。身后的尾巴烦躁地拍打了两下床单，然后无力地耷拉下来。

过了几分钟，她又把手机捡起来。

最后，她只发了四个字："茉璃，在吗"

发送。

浅紫盯着屏幕，心跳有点快。狐尾不自觉地翘了起来，尾尖微微颤抖。

几分钟后，回复来了："在喵"

浅紫松了口气，嘴角不自觉地扬了起来。

她又打了一行字："我的伤好多了"

茉璃："嗯喵"

浅紫等着她继续说点什么，但茉璃没有再发消息过来。

浅紫犹豫了一下，又发了一条："谢谢你救了我"

茉璃："不客气喵"

浅紫看着屏幕，不知道该说什么了。

她点开茉璃的头像，是一只黑色的猫咪，眼睛是粉红色的。点开空间，动态很多，最新条是昨天发的，内容是一张夕阳的照片，配文："今天的太阳好大喵"

浅紫忍不住笑了。

接下来的几天，两人断断续续地聊着。

浅紫每天都会给茉璃发消息，问她在干嘛、吃了什么、有没有出去玩。茉璃的回复永远很简短，总是带着"喵"。

"在睡觉喵"
"吃了什么喵？"
"出去玩了吗喵？"

浅紫发现茉璃不太懂人情世故。

有一次，浅紫发了一张自拍，问茉璃："我这样好看吗？"

茉璃回了三个字："还行喵"

浅紫盯着那三个字看了很久，不知道该生气还是该笑。尾巴在身后甩了甩。

有一次，浅紫问她："你为什么总是说'喵'？"

茉璃回了一段很长的语音："因为我是猫娘喵，猫娘就是要'喵'的喵，这是常识喵"

到了第七天，父亲在饭桌上说了一件事。

"下周我和你妈要出差，大概要去一周。"

浅紫的筷子停在半空："出差？"

"有个项目要对接。"父亲说，"你一个人在家没问题吧？"

浅紫点了点头："没问题。"

“要去哪？”

没有回应

良久

母亲说了一句："修炼的时候小心点，别再受伤了。"

"知道了。"

浅紫低下头，继续吃饭。

她想起茉璃，犹豫要不要告诉她这件事。狐尾不知不觉在椅子腿上缠了一圈又松开。
