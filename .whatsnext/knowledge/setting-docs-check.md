# 写新场景/设定前先查或先问设定文档

AGENTS.md 已规定"环境描写如有提供文档需先查设定文档"。实践验证过违反它的代价：写满月城时未查设定，写出的"空气干燥""连绵沙丘""沙漠博物馆"全部与设定冲突（满月城是降水充沛的平原城市、有河流穿城），被用户逐条批注返工。

操作规则：

1. 大纲出现新地点/新设定名词时，先在仓库及周边目录搜索是否存在对应设定文档（已知设定库位于 `C:\World\Universe\` ）。
2. 找不到就先问用户，不要凭常识编造气候、地形、经济、社会氛围等设定。
3. 设定文档内容优先于一切"合理想象"；文档没写的细节才可自由发挥，且不得与文档冲突。
