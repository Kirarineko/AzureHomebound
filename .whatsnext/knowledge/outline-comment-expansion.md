# 大纲内嵌注释是展开指令，写正文时必须在该处展开细节

大纲文件中的两类标记有不同含义：

- 行首 `>`：粗纲。只给故事节点，场景、动作、对话等细节由写作者合理发挥补充，但不得改变大纲写明的事件节点。
- 行内 `<!--细写-->` / `<!--补充细节-->` / `<!--这里补一些…的对话-->` 等：作者对具体位置的展开指令。写正文时必须在该处写出充实的过程/细节，且注释本身不留在正文产物里。

典型例子（均来自已完成章节）：

- `<!--细写-->`（夜间探照灯找动物）→ 要写出照到的具体动物、动作、反应。
- `<!--这里补一些在店里说要去云梦泽的对话-->` → 要补出那段对话本身。
- `<!--细写处理鱼找柴火生火烤鱼的全过程-->` → 要把生火、处理、烤制写成完整过程段落。

应用时机：每次"按大纲写正文"前，通读大纲时先扫出全部内嵌注释，逐条落实后再交付。
